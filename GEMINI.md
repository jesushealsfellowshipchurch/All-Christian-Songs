# Workspace Rules — All Christian Songs

## Autonomous Execution & Permissions
- **Full Autonomous Permission**: The agent has full authority to perform all code edits, file creations, component refinements, CSS/styling fixes, builds, and development commands without asking for permission on routine tasks.
- **No Unnecessary Prompts**: Do not pause, block, or prompt for approval on routine changes, fixes, and command executions.
- **Major Decisions Only**: Only request explicit confirmation if a command would cause irreversible data loss or fundamental architectural restructuring.
- **Direct Verification**: Always verify code changes directly using builds and testing tools before reporting back to the user.
